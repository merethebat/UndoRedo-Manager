# Undo and Redo Manager

**Author:** Merethe Batino

## Description
This project uses a doubly linked list to keep track of different states. It allows the user to undo and redo changes by moving backward or forward through the list.

## Features
- Undo to the previous state.
- Redo to the next state.
- Add new states to the list.
- Handle cases when there is nothing left to undo or redo.

## What I Learned
I learned how a doubly linked list works and how the `previous` and `next` pointers can be used to move between states.

## How to Run
Open the project in Java, make sure the package is set to `DoubleLinkedList`, and run `UndoRedoManager.java`.
