# Undo and Redo Manager

**Author:** Merethe Batino

This Java program uses a doubly linked list to keep track of different states. Undo moves to the previous state, and Redo moves to the next state when one is available. If a new state is added after undoing, the old redo path is cleared.

## Run

- Save the file as `UndoRedoManager.java`
- inside the `DoubleLinkedList` package folder
- then run the `UndoRedoManager` class from IDE
